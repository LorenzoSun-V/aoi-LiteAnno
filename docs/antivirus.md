# 杀毒软件把 LiteAnno.exe 报成病毒怎么办

测试版的 LiteAnno.exe 没有数字签名。Windows Defender 等杀毒软件有时会把没有签名、刚编译出来、还没人用过的程序误判为病毒，常见的名字带 `!ml`（例如 `Trojan:Win32/Bearfoos.A!ml`）。`!ml` 表示这是机器学习“猜”的，不是匹配到了已知病毒。每次重新编译，exe 的内容都会变，所以新版本可能再被误报一次。

只从本项目 GitHub 打包流程下载的 zip 才可信。来路不明的 exe 不要用下面的办法放行。

## 一、提交给微软复核（推荐，免费）

1. 打开 https://www.microsoft.com/en-us/wdsi/filesubmission ，用微软账号登录。
2. 身份选 **Software developer**，产品选 **Microsoft Defender Antivirus**。
3. 上传被报毒的 zip（或解压出的 LiteAnno.exe）。
4. 选择 **Incorrectly detected as malware/malicious**，检测名填杀毒软件显示的名字，例如 `Trojan:Win32/Bearfoos.A!ml`。
5. 说明里写：这是自己用 GitHub Actions 从源码编译的开源图像标注工具，未签名，请求复核误报。

一般几小时到三天会有结果。通过后，同一个文件在所有电脑上都不再报；之后更新病毒库即可：管理员权限的 PowerShell 里运行 `Update-MpSignature`。

其他杀毒软件（360、火绒、腾讯电脑管家等）也都有误报反馈入口，在软件的隔离区或官网“误报申诉”里提交同一个文件。

## 二、在现场电脑上放行（临时）

复核结果出来之前，可以只放行 LiteAnno 所在的文件夹：

1. 打开“Windows 安全中心” → “病毒和威胁防护” → “病毒和威胁防护设置”下的“管理设置”。
2. 找到“排除项” → “添加或删除排除项” → “添加排除项” → “文件夹”，选 LiteAnno.exe 所在的文件夹（例如 `D:\LiteAnno`）。
3. 如果 exe 已被隔离：“病毒和威胁防护” → “保护历史记录”，找到这一条，选“操作” → “还原”。

只排除这一个文件夹，不要关闭实时保护，也不要把整个磁盘或“下载”文件夹加入排除。

## 三、以后的版本

exe 里带有版本信息（文件属性 → 详细信息：产品名、版本号、说明），可以确认是哪一次编译的。若以后要彻底减少误报，办法是代码签名，需要购买证书或订阅签名服务；目前不做。
